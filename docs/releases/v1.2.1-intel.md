## English

DPI Bridge 1.2.1 hardens the Intel distribution pipeline ahead of making the
repository public. The Discord connectivity flow and user settings are
unchanged.

### Security and privacy improvements

- ByeDPI was updated to commit
  `ba532298de7b28cfe854aea83d061369d13ca290` from the official
  `hufrea/byedpi` repository.
- `ciadpi` is no longer stored as an opaque binary; it is rebuilt from the
  pinned source during release builds.
- Local usernames and build paths were stripped from release binaries.
- macOS extended attributes and AppleDouble entries were removed from ZIPs.
- Preflight checks now verify binary paths, ZIP metadata, and provenance.

### Installation

1. Extract `DPI-Bridge-1.2.1-intel.zip`.
2. Move `DPI-Bridge.app` to Applications.
3. Follow the Gatekeeper and encrypted DNS profile steps in the README.

The package is ad-hoc signed and not Apple-notarized. Use the README's **Open
Anyway** method; do not disable Gatekeeper globally.
