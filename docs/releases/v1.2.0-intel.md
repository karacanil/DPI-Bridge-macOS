Intel sürümüdür. Daha önce doğrulanan Discord bağlantı akışı değişmeden korunur.

- Uygulama, executable, Swift target, profil görünen adı ve dokümanlar
  **DPI Bridge** olarak yeniden markalandı.

1. Eski uygulamada **Durdur** düğmesine basıp uygulamadan çıkın.
2. `SplitWire-Turkey.app` dosyasını Applications klasöründen kaldırın.
3. `DPI-Bridge-1.2.0-intel.zip` dosyasını açıp `DPI-Bridge.app` dosyasını
   Applications klasörüne taşıyın.
4. Mevcut şifreli DNS profili çalışmaya devam eder; yeniden kurmanız gerekmez.

Paket ad-hoc imzalı ve Apple tarafından notarize edilmemiştir. README'deki
**Yine de Aç / Open Anyway** adımlarını kullanın; Gatekeeper'ı genel olarak

## English

DPI Bridge 1.2.0 is the first stable Intel release under the project's new,
location-neutral name. The previously verified Discord connectivity flow is
unchanged.

### Changes

- The app, executable, Swift target, profile display name, and documentation
  were rebranded as **DPI Bridge**.
- The repository is now named `DPI-Bridge-macOS`.
- The bundle identifier and DNS payload identifier were retained for upgrade
  compatibility.
- The restore flow cleans both new and legacy helper process files.

### Upgrading from SplitWire-Turkey

1. Click **Durdur** in the old app and quit it.
2. Remove `SplitWire-Turkey.app` from Applications.
3. Extract `DPI-Bridge-1.2.0-intel.zip` and move `DPI-Bridge.app` to Applications.
4. Your existing encrypted DNS profile remains compatible; no reinstall is
   required.

The package is ad-hoc signed and not Apple-notarized. Follow the README's
**Open Anyway** steps; do not disable Gatekeeper globally.
