## English

This pre-release is the Apple Silicon 1.2.1 Beta 1 package produced with the
hardened distribution pipeline. It contains native `arm64` binaries for M1,
M2, M3, and M4 family Macs.

### Security and privacy improvements

- ByeDPI was updated to the official upstream commit
  `ba532298de7b28cfe854aea83d061369d13ca290` and rebuilt from source.
- Local user/build paths and macOS AppleDouble metadata were removed.
- Architecture, signature, ZIP integrity, localhost bind, and provenance checks
  passed.

This remains a pre-release until a clean-install test is completed on physical
Apple Silicon hardware. If needed, use `TARGET_ARCH=arm64 ./build.sh` from the
README to build from source.

The package is not Apple-notarized. Use the README's **Open Anyway** method; do
not disable Gatekeeper globally.
