## Türkçe

Bu ön sürüm, Intel işlemcili Mac'ler için doğrulanmış Discord bağlantı çözümünü içerir.

### İçerik

- macOS 13 Ventura veya sonrası için Intel `x86_64` uygulaması
- Yalnızca `127.0.0.1:1080` üzerinde dinleyen ByeDPI SOCKS5 proxy
- Yalnızca `127.0.0.1:1081` üzerinde dinleyen Discord güncelleyicisi HTTP→SOCKS köprüsü
- Discord DNS engellemesi için önerilen Cloudflare şifreli DNS profili
- Discord'un **Checking for Updates** ekranında kalmasına yönelik çözüm
- Yardımcı süreçlerin güvenli ve doğrulanabilir biçimde durdurulması

### Beta 2 güvenlik düzeltmesi

ByeDPI artık açıkça `--ip 127.0.0.1` parametresiyle başlatılır. Böylece SOCKS5 portu tüm ağ arayüzlerine değil yalnızca bu Mac'e açılır. Geri yükleme scripti de normal sonlandırmaya yanıt vermeyen, SplitWire'a ait olduğu doğrulanmış yardımcı PID'yi güvenle kapatır.

### Beta 3 değişiklikleri

- Arayüz varsayılan olarak Türkçedir; üst menüden **English** seçilebilir.
- Hakkında ekranındaki eski geliştirici kişisel bilgileri kaldırıldı.
- Discord macOS Launch Services üzerinden başlatılır. SplitWire klavye girdilerini izlemez ve **Input Monitoring / Giriş İzleme** iznine ihtiyaç duymaz.
- Discord, sistem genelinde Push-to-Talk veya global kısayollar için kendi adına Input Monitoring izni isteyebilir. Bu özellikleri kullanmıyorsanız reddedebilirsiniz.

### Kurulum

1. `SplitWire-Turkey-1.1.0-intel-beta.3.zip` dosyasını indirip arşivden çıkarın.
2. `SplitWire-Turkey.app` uygulamasını `/Applications` klasörüne taşıyın.
3. Uygulamayı bir kez açmayı deneyin ve uyarıda **Bitti / Done** seçeneğine basın.
4. Sistem Ayarları → Gizlilik ve Güvenlik bölümünde aşağı kaydırıp SplitWire için **Yine de Aç / Open Anyway** düğmesine basın.
5. Parolanız veya Touch ID ile onaylayıp son uyarıda **Aç / Open** seçeneğini kullanın.
6. Aşağıdaki şifreli DNS profili adımlarını tamamlayın.
7. SplitWire'a dönüp **Discord'u Başlat** düğmesine basın.

**Yine de Aç / Open Anyway** düğmesi ilk başarısız açma denemesinden sonra yaklaşık bir saat kullanılabilir ve yalnızca bu uygulama için istisna oluşturur. [Apple'ın resmi yönergesi](https://support.apple.com/guide/mac-help/open-an-app-by-overriding-security-settings-mh40617/mac).

### Şifreli DNS profilini yükleme

Bu profil sistem genelindeki DNS sorgularını Cloudflare DNS over HTTPS'e yönlendirir. Uygulamanın **Şifreli DNS Profilini Aç** düğmesi profili yalnızca macOS'a aktarır; yükleme işlemini ayrıca onaylamanız gerekir.

1. SplitWire içindeki **Şifreli DNS Profilini Aç** düğmesine basın.
2. macOS profilin indirildiğini/aktarıldığını bildirince Sistem Ayarları'nı açın.
3. **Genel → Aygıt Yönetimi / General → Device Management** bölümüne gidin. Seçenek görünmüyorsa SplitWire'daki profil düğmesine yeniden basın.
4. **İndirilenler / Downloaded** bölümündeki **SplitWire Cloudflare Encrypted DNS** profiline çift tıklayın.
5. Yüklemeden önce içeriği kontrol edin:
   - Kuruluş: **SplitWire Turkey**
   - İçerik: yalnızca **Cloudflare Encrypted DNS / DNS Settings**
   - DNS adresi: `https://cloudflare-dns.com/dns-query`
6. Profil henüz imzalı olmadığı için macOS **İmzasız / Unsigned** gösterebilir. Yalnızca ZIP checksum'u bu nottaki değerle eşleşiyorsa devam edin.
7. **Sürdür / Continue**, ardından **Yükle / Install** düğmesine basın ve parola veya Touch ID ile onaylayın.
8. Profilin Aygıt Yönetimi'nde **Yüklendi / Installed** bölümünde göründüğünü doğrulayın.

Profil daha sonra **Sistem Ayarları → Genel → Aygıt Yönetimi** altında seçilip eksi (`−`) düğmesiyle tamamen kaldırılabilir. Apple'ın profil kurma ve kaldırma adımları için [resmî macOS kılavuzuna](https://support.apple.com/guide/mac-help/mh35561/mac) bakın.

### Önemli kısıtlama

Bu beta sürüm ad-hoc imzalıdır ve Apple tarafından notarize edilmemiştir; çünkü projede henüz bir Developer ID sertifikası yapılandırılmamıştır. Bu nedenle macOS'un Apple'ın uygulamanın zararlı yazılım içermediğini doğrulayamadığını belirten uyarısı beklenir. Gatekeeper'ı rastgele `xattr`, `sudo` veya sertifika komutlarıyla devre dışı bırakmayın. Genel dağıtıma yönelik kararlı sürüm Developer ID ile imzalanmalı ve Apple tarafından notarize edilmelidir.

## English

This pre-release packages the verified Discord connectivity flow for Intel Macs.

### Included

- Intel `x86_64` build for macOS 13 Ventura or newer
- ByeDPI SOCKS5 proxy listening only on `127.0.0.1:1080`
- Discord updater HTTP-to-SOCKS bridge listening only on `127.0.0.1:1081`
- Recommended Cloudflare encrypted DNS profile for Discord DNS blocking
- Fix for Discord getting stuck at **Checking for Updates**
- Safe and verifiable shutdown of helper processes

### Beta 2 security fix

ByeDPI is now launched explicitly with `--ip 127.0.0.1`, so its SOCKS5 port is available only to this Mac instead of every network interface. The restore script also safely terminates a verified SplitWire-owned helper PID when it does not respond to a normal termination request.

### Beta 3 changes

- The interface defaults to Turkish; **English** can be selected from the top menu.
- Personal information about previous developers was removed from the About screen.
- Discord is launched through macOS Launch Services. SplitWire does not monitor keystrokes and does not require **Input Monitoring** permission.
- Discord may request Input Monitoring in its own name for system-wide Push-to-Talk or global shortcuts. You can deny it if you do not use those features.

### Install

1. Download and extract `SplitWire-Turkey-1.1.0-intel-beta.3.zip`.
2. Move `SplitWire-Turkey.app` to `/Applications`.
3. Try to open the app once, then click **Done** in the warning.
4. Open System Settings → Privacy & Security, scroll down, and click **Open Anyway** for SplitWire.
5. Authenticate with your password or Touch ID, then click **Open** in the final prompt.
6. Complete the encrypted DNS profile steps below.
7. Return to SplitWire and click **Discord'u Başlat**.

The **Open Anyway** button is available for about an hour after the failed launch attempt and creates an exception only for this app. See [Apple's official instructions](https://support.apple.com/guide/mac-help/open-an-app-by-overriding-security-settings-mh40617/mac).

### Install the encrypted DNS profile

This profile sends system-wide DNS queries to Cloudflare DNS over HTTPS. The **Şifreli DNS Profilini Aç** button only hands the profile to macOS; you must approve the installation separately.

1. Click **Şifreli DNS Profilini Aç** in SplitWire.
2. After macOS reports that the profile was downloaded/received, open System Settings.
3. Go to **General → Device Management**. If this entry is missing, click the profile button in SplitWire again.
4. Under **Downloaded**, double-click **SplitWire Cloudflare Encrypted DNS**.
5. Review the profile before installing it:
   - Organization: **SplitWire Turkey**
   - Payload: only **Cloudflare Encrypted DNS / DNS Settings**
   - DNS URL: `https://cloudflare-dns.com/dns-query`
6. The profile may appear as **Unsigned** because it is not yet cryptographically signed. Continue only if the ZIP checksum matches the value in these notes.
7. Click **Continue**, then **Install**, and authenticate with your password or Touch ID.
8. Confirm that the profile appears under **Installed** in Device Management.

You can later remove it completely from **System Settings → General → Device Management** by selecting it and clicking the minus (`−`) button. See [Apple's official macOS profile guide](https://support.apple.com/guide/mac-help/mh35561/mac) for installation and removal details.

### Important limitation

This beta is ad-hoc signed and is not Apple-notarized because no Developer ID certificate is configured. Therefore, the macOS warning that Apple could not verify the app is free of malware is expected. Do not bypass Gatekeeper with random `xattr`, `sudo`, or certificate commands. A broadly distributed stable release should be Developer ID signed and notarized.
