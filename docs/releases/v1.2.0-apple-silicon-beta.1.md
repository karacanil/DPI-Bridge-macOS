## Türkçe

Bu pre-release, DPI Bridge adıyla yayımlanan ilk Apple Silicon beta paketidir.
M1, M2, M3 ve M4 ailesindeki Mac'ler için doğal `arm64` binary'ler içerir.

Uygulama, ByeDPI yardımcısı ve Discord güncelleyici köprüsünün mimari, statik
güvenlik, ZIP bütünlüğü ve ad-hoc imza kontrolleri geçti. Fiziksel bir Apple
Silicon Mac'te sıfırdan kurulum testi henüz tamamlanmadığı için pre-release
olarak kalır.

### Kurulum ve yükseltme

- Yeni kurulumda `DPI-Bridge-1.2.0-apple-silicon-beta.1.zip` dosyasını açıp
  `DPI-Bridge.app` dosyasını Applications klasörüne taşıyın.
- Eski `SplitWire-Turkey.app` kuruluysa önce **Durdur** düğmesine basıp eski
  uygulamayı kaldırın.
- Mevcut şifreli DNS profili uyumludur ve yeniden kurulması gerekmez.
- Paket sorun çıkarırsa README'deki `TARGET_ARCH=arm64 ./build.sh` kaynak
  derleme yöntemini kullanabilirsiniz.

Paket Apple tarafından notarize edilmemiştir. README'deki **Yine de Aç / Open
Anyway** adımlarını kullanın; Gatekeeper'ı genel olarak devre dışı bırakmayın.

## English

This pre-release is the first Apple Silicon beta published under the DPI Bridge
name. It contains native `arm64` binaries for Macs in the M1, M2, M3, and M4
families.

The app, ByeDPI helper, and Discord updater bridge passed architecture, static
security, ZIP integrity, and ad-hoc signature checks. It remains a pre-release
until a clean-install test is completed on physical Apple Silicon hardware.

### Install and upgrade

- For a new installation, extract
  `DPI-Bridge-1.2.0-apple-silicon-beta.1.zip` and move `DPI-Bridge.app` to
  Applications.
- If `SplitWire-Turkey.app` is installed, click **Durdur** and remove the old app
  first.
- The existing encrypted DNS profile remains compatible and does not need to be
  reinstalled.
- If the package fails, use the README's `TARGET_ARCH=arm64 ./build.sh` source
  build instructions.

The package is not Apple-notarized. Follow the README's **Open Anyway** steps;
do not disable Gatekeeper globally.
