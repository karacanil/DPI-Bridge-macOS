Turkey beta paketidir.

- Apple M1, M2, M3 ve M4 ailesindeki işlemcilere sahip Mac'ler

kurulum testi yapılmadığı için bu sürüm beta olarak yayımlanır.

1. `SplitWire-Turkey-1.1.0-apple-silicon-beta.1.zip` dosyasını indirip açın.
2. `SplitWire-Turkey.app` uygulamasını Applications klasörüne taşıyın.

4. SplitWire içinden **Discord'u Başlat** düğmesine basın.

Gatekeeper'ı `xattr`, `sudo` veya benzeri genel komutlarla devre dışı bırakmayın.

## English

This pre-release is the first SplitWire Turkey beta package for Apple Silicon
Macs.

### Supported devices

- Macs with Apple M1, M2, M3, or M4 family processors
- macOS 13 Ventura or later
- Discord installed at `/Applications/Discord.app`

The application, ByeDPI helper, and Discord updater bridge are native `arm64`
binaries. Static security, architecture, ZIP integrity, and ad-hoc signature
checks have passed. This release remains a beta because it has not yet completed
a clean-install test on physical Apple Silicon hardware.

### Installation

1. Download and extract `SplitWire-Turkey-1.1.0-apple-silicon-beta.1.zip`.
2. Move `SplitWire-Turkey.app` to Applications.
3. Follow the Gatekeeper and encrypted DNS profile steps in the README.
4. Click **Discord'u Başlat** in SplitWire.

The package is not Apple-notarized, so the macOS verification warning is
expected. Do not disable Gatekeeper globally with `xattr`, `sudo`, or similar
commands. Use the **Open Anyway** method documented in the README.

If the beta package fails, see **Kaynaktan derleme** in the README and build it
on your Apple Silicon Mac with `TARGET_ARCH=arm64 ./build.sh`.
