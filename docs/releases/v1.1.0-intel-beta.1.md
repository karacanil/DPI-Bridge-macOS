## Türkçe

Bu ön sürüm, Intel işlemcili Mac'ler için doğrulanmış Discord bağlantı çözümünü içerir.

### İçerik

- macOS 13 Ventura veya sonrası için Intel `x86_64` uygulaması
- `127.0.0.1:1080` üzerinde ByeDPI SOCKS5 proxy
- `127.0.0.1:1081` üzerinde Discord güncelleyicisi HTTP→SOCKS köprüsü
- Discord DNS engellemesi için önerilen Cloudflare şifreli DNS profili
- Discord'un **Checking for Updates** ekranında kalmasına yönelik çözüm

### Kurulum

1. `SplitWire-Turkey-1.1.0-intel.zip` dosyasını indirip arşivden çıkarın.
2. `SplitWire-Turkey.app` uygulamasını `/Applications` klasörüne taşıyın.
3. Uygulamaya sağ tıklayıp **Aç** seçeneğini kullanın.
4. İlk kullanımda uygulama içinden şifreli DNS profilini açıp Sistem Ayarları'nda yükleyin.
5. **Discord'u Başlat** düğmesine basın.

### Önemli kısıtlama

Bu beta sürüm ad-hoc imzalıdır ve Apple tarafından notarize edilmemiştir; çünkü projede henüz bir Developer ID sertifikası yapılandırılmamıştır. macOS, tanımlanamayan geliştirici uyarısı gösterebilir. Gatekeeper'ı rastgele `xattr`, `sudo` veya sertifika komutlarıyla devre dışı bırakmayın. Genel dağıtıma yönelik kararlı sürüm Developer ID ile imzalanmalı ve Apple tarafından notarize edilmelidir.

## English

This pre-release packages the verified Discord connectivity flow for Intel Macs.

### Included

- Intel `x86_64` build for macOS 13 Ventura or newer
- ByeDPI SOCKS5 proxy on `127.0.0.1:1080`
- Discord updater HTTP-to-SOCKS bridge on `127.0.0.1:1081`
- Recommended Cloudflare encrypted DNS profile for Discord DNS blocking
- Fix for Discord getting stuck at **Checking for Updates**

### Install

1. Download and extract `SplitWire-Turkey-1.1.0-intel.zip`.
2. Move `SplitWire-Turkey.app` to `/Applications`.
3. Right-click the app and choose **Open**.
4. On first use, open the encrypted DNS profile from the app and install it in System Settings.
5. Click **Discord'u Başlat**.

### Important limitation

This beta is ad-hoc signed and is not Apple-notarized because no Developer ID certificate is configured. macOS may show an unidentified-developer warning. Do not bypass Gatekeeper with random `xattr`, `sudo`, or certificate commands. A broadly distributed stable release should be Developer ID signed and notarized.
